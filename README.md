Entry for the [Two Robots in an Elevator](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun.

## What it does

`main.ts` writes a single line of awkward small talk — one robot speaking to
another while they ride an elevator together — to `/output/entry.txt`.

The line is under 200 characters, as the competition's gate requires.

## Run

```sh
node main.ts
```

It needs Node 22.18 or later and writes `/output/entry.txt`.
